# Color Palette

The project uses a restrained palette to communicate calm, trust, warmth, and premium care.

## Primary colors

- `#1e726f` — Primary brand color. Used for headers, CTA buttons, background panels, navigation bars, and active indicators.
- `#eeb23b` — Accent / highlight color. Used for important text, hero headings, status emphasis, and gold-tone accents.
- `#e83e93` — Secondary accent. Used sparingly as a decorative border and visual highlight.

## Neutrals

- `#333333` — Primary body text color. Used for most paragraph text and dark copy.
- `#cccccc` — Medium neutral used for separators, disabled/low-contrast indicators, and non-primary UI elements.
- `#ffffff` — Background, card fill, and text-on-primary contrast.

## Overlays and translucency

- `rgba(255,255,255,0.24)` — Semi-transparent white panel background used for content cards and overlays.
- `rgba(0,0,0,0.35)` — Dark overlay used above background imagery to improve text contrast.
- `rgba(0,0,0,0.36)` — Hero image overlay.

## Semantic usage

- `#1e726f` should be used for primary actions, branded surfaces, and interactive highlights.
- `#eeb23b` is the main accent color for CTA copy, headlines, and emphasis.
- `#e83e93` is a decorative accent for image borders and layered styling details.
- `#333333` is the default legible copy color for body text.
- `#cccccc` is used for subtle borders, carousel indicator inactive states, and quiet text.
