# Design System Knowledge Base

This folder captures the design language used by the Holistic Therapy Massage project. It is intended for agents and developers who need to understand and maintain the visual system, layout patterns, component behavior, and brand styling in this app.

The repository does not currently define a formal token library, so these files infer the core design tokens and principles from the running app and source code.

## Contents

- `colors.md` — core color palette and semantic usage.
- `typography.md` — font families, sizes, weights, and text styling patterns.
- `spacing-layout.md` — spacing, layout structure, grid and sizing rules.
- `components.md` — reusable UI patterns and component behavior.
- `assets.md` — imagery, fonts, and asset conventions.

## How to use this knowledge base

- Use the token files to make consistent UI updates.
- Use the components file to understand how page sections are constructed and when to reuse patterns.
- Use this documentation as the single source of truth until a full design system implementation is introduced.
