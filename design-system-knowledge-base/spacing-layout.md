# Spacing and Layout

The layout is built around generous padding, clear vertical rhythm, and layered imagery.

## Core spacing values

- `24px` — Primary horizontal padding on most sections, content cards, and page gutters.
- `16px` — Small vertical gaps, icon spacing, and header padding.
- `32px` — Larger content separation and CTA padding.
- `48px` — Section separation and large content grouping spacing.
- `60px` / `72px` — Extra-large top margins and call-to-action spacing.

## Border radius

- `12px` — Primary card and image corner radius.
- `16px` — Panel radius for translucent content blocks.
- `20px` — Decorative overlay border radius on accent elements.
- `1000px` — Fully rounded pill buttons.

## Layout structure

- The page is a single vertical scroll experience.
- Content is centered within a full-width wrapper.
- Section widths are fluid, but internal padding is consistently `24px`.
- Many panels use a translucent white surface to float above photographic backgrounds.

## Section sizing

- Hero section height: `400px`.
- About collage container height: `430px`.
- CTA footer section minimum height: `551px`.
- Testimonial carousel uses full-width horizontal snapping for slides.

## Visual layering

- Background images are used full-screen behind content and are darkened with overlays.
- Content cards are layered with absolute-positioned decorative accents and blurred glow elements.
- Images frequently use `object-cover` and `rounded-[12px]` for a polished, photo-driven presentation.
